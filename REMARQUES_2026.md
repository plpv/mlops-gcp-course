Remarques suite à l'itération de 2026 à prendre en compte pour améliorer l'itération suivante :

- Les étudiants utilisent `conda` pour gérer els environnements. Il y a eu des difficultés d'installation de packages pour le `lab01`. Prévoir un guide d'installation avec `conda`.
- Pour les notebooks sur Vertex AI, les étudiants peuvent ne pas réussir à lancer le notebook s'ils ne sont pas sur Chrome
- Bien insister sur les parties de Clean-up ! Malgré les sections dédiées dans les notebooks et les (nombreux) rappels durant le TD, beaucoup d'étudiants oublie de supprimer leurs ressources, parfois ignorant les TO DO des ces sections clean-up (peut-être enlever ces TO DO et juste demander aux étudiants de run ces cellules)
- Revoir certaines questions qui sont peut-être trop guidées.
- Garder les liens vers la documentation (TRES apprécié par les étudiants), mais insister sur le fait de les utiliser (certains étudiants venaient me voir pour des questions, alors que la réponse était dans la doc juste au-dessus du TO DO, ils n'ont malheureusement plus ce réflexe)
